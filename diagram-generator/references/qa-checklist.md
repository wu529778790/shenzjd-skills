# QA 质量检查清单

图表生成完成后，逐项检查：

## 视觉一致性

- [ ] 所有组件使用统一的设计系统颜色
- [ ] 同类组件大小一致
- [ ] 描边宽度统一（1.5px）
- [ ] 圆角半径一致（6px）

## 布局合理性

- [ ] 组件间距均匀（垂直 40px，水平 30px）
- [ ] 区域内组件居中
- [ ] 流向清晰（LTR 或 TTB）
- [ ] 无组件重叠
- [ ] 无箭头穿过组件

## 颜色规范

- [ ] Primary (cyan) 用于前端/输入
- [ ] Secondary (emerald) 用于后端/处理
- [ ] Tertiary (violet) 用于数据库/存储
- [ ] Accent (amber) 用于云/基础设施
- [ ] Alert (rose) 用于错误/警告

## 文字可读性

- [ ] 组件名清晰可读
- [ ] 描述文字大小合适（9px）
- [ ] 箭头标签不遮挡线条
- [ ] 中文文字已加宽处理

## SVG 规范

- [ ] viewBox 包含所有元素
- [ ] 四周有 30px padding
- [ ] XML 特殊字符已转义（`&` → `&amp;`）
- [ ] `<style>` 使用 CDATA 包裹
- [ ] 图层顺序正确（背景→边界→箭头→遮罩→组件→文字→图例→标题）

## 边界处理

- [ ] 区域边界完全包含子组件
- [ ] 区域标签在边界顶部上方
- [ ] 无元素超出 viewBox

## 最终检查

- [ ] 图表标题清晰
- [ ] 图例完整
- [ ] 整体美观专业
